# Measures - 度量参考

## 文章重点总结

- **度量**表示一组数据点的聚合；常用参数：**type**（count、sum、avg、count_distinct、min、max、number 等）、**sql**（聚合表达式或列）、**filters**（条件数组）、**format**（currency、percent 等）、**drill_members**（下钻维度）、**description**、**meta**。**number** 型可写任意 SQL 表达式，用于计算度量。**rolling_window**、**time_shift**、**multi_stage**、**group_by**、**order_by**、**reduce_by**、**case** 等见 Multi-stage calculations、Concepts。
